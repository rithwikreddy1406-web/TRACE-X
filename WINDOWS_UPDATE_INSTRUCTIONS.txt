TRACE-X v8 GITHUB UPDATE — WINDOWS POWERSHELL (no WSL required for Git)

1. Download TRACE-X-v8-GitHub-UPDATE.zip to Windows Downloads.
2. Open PowerShell. Run (adjust if your project has a different path):

$project = "$env:USERPROFILE\Downloads\tracex_v7_dynamic_dataset"
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\TRACE-X-v8-GitHub-UPDATE.zip" -DestinationPath $project -Force
Set-Location $project

3. Check expected updates before publishing:

git status --short
git diff --stat
git remote -v

4. Check the staged file list, then commit and push:

git add -A
git diff --cached --stat
git commit -m "Add v8 UTXO investigator and static Netlify demo"
git push
