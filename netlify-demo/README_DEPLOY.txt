TRACE-X STATIC NETLIFY DEMO (v8 visualization, v7 analytics export)

1. Upload the ZIP or extracted site folder to Netlify Drop. If ZIP upload is not offered, extract the ZIP and drag the contained site folder.
2. Open your Netlify URL. All views read only the bundled, precomputed synthetic JSON.
3. Go to Data Intelligence to switch between 120-transaction UTXO fixture and 2,008-transaction wallet-only fixture.
4. Dataset uploads, Python ML inference, live investigation API, and WSL processing are NOT available in the static build. Use your local TRACE-X project and start python backend/v7_server.py --port 8765 for these workflows.
5. The 120-row synthetic UTXO fixture has deliberately inconsistent records. Do not call any alert a confirmed real-world crime.
6. Cases/settings are stored only in the viewer browser local storage. Do not enter sensitive details into a public deployment.
